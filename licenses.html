The 0.2.2 baseline uses Korean–English ONNX translation. The 0.3.0 candidate is being developed for a free public Steam Early Access alpha, not a final 1.0 release. The app has not been released; audio, game performance, minimum hardware, fresh Steam installation checks and Valve approval remain pending. Publishing a model pack does not mean the app is released or translation quality is validated.

0.3 후보는 위 구성요소의 전문·저작권 고지를 네이티브 runtime의 licenses 폴더에 동봉합니다. marisa의 BSD-2-Clause/LGPL 이중 라이선스 중 BSD 조건을 선택했습니다. OpenCC s2t/t2s 설정은 동봉 텍스트 사전을 읽도록 형식·경로만 변경했고 사전 내용은 수정하지 않았습니다. 번역 worker는 별도 C++ 프로세스이며 Python 런타임을 동봉하지 않습니다.
The 0.3 candidate includes full license texts and copyright notices in the native runtime's licenses directory. marisa is used under the BSD-2-Clause option of its BSD/LGPL dual license. The OpenCC s2t/t2s configurations change only the format and paths used to read bundled text dictionaries; dictionary contents are unmodified. Translation runs in a separate C++ worker, with no bundled Python runtime.

.NET 10 LTS 후보의 Microsoft.Extensions.Hosting, DependencyInjection.Abstractions, Logging.Abstractions, Options, Http 10.0.13은 .NET Foundation and Contributors의 MIT 라이선스입니다. Windows API 키 보호에 사용하는 System.Security.Cryptography.ProtectedData는 동봉 WindowsDesktop 런타임에서 제공합니다.
The .NET 10 LTS candidate uses Microsoft.Extensions.Hosting, DependencyInjection.Abstractions, Logging.Abstractions, Options and Http 10.0.13 under the .NET Foundation and Contributors' MIT license. System.Security.Cryptography.ProtectedData for Windows API-key protection is supplied by the bundled WindowsDesktop runtime.

동봉한 세 글꼴의 OFL 전문은 fonts/Pretendard-OFL.txt · fonts/JetBrainsMono-OFL.txt · fonts/GowunBatang-OFL.txt 에 있고, Pretendard 는 앱 배포물에도 함께 들어 있습니다. OFL 조건에 따라 글꼴을 단독으로 판매하지 않습니다.
Full OFL texts for the three bundled fonts are linked above; none of them is sold on its own.

이 홈페이지의 글꼴은 여기 나오는 글자(2,056자)만 남기고 잘라 냈습니다. 자르는 것은 OFL 이 말하는 “고친 판(Modified Version)”입니다. Pretendard 는 저작권 줄에 with Reserved Font Name 'Pretendard' 가 붙어 있어, OFL 제3조에 따라 고친 판이 그 이름을 쓸 수 없습니다. 그래서 자른 판의 이름만 Onmal Sans 로 바꿨습니다 — 글꼴 파일 안의 저작권(길형진)과 라이선스 문자열은 그대로입니다. Gowun Batang 과 JetBrains Mono 는 Reserved Font Name 이 없어 이름을 그대로 씁니다.
The bundled fonts are subsets. Pretendard carries a Reserved Font Name, so the subset is renamed “Onmal Sans” per OFL §3; its copyright and license strings are unchanged.

동봉하지 않은 글꼴은 시스템에 이미 있는 것으로 대체됩니다. 배포물에 들어가지 않으므로 OFL 의무도 생기지 않습니다.
Fonts that are not bundled are substituted from the system and carry no OFL obligation here.

선택 팩의 Noto 파일은 Noto Fonts revision ffebf8c1ee449e544955a7e813c54f9b73848eac와 Noto CJK revision f8d157532fbfaeda587e826d4cd5b21a49186f7c에서 가져왔습니다. 팩의 fonts 폴더에는 LICENSE-Noto.txt, LICENSE-Noto-CJK.txt와 font-provenance.json을 포함하며 글꼴을 단독으로 판매하지 않습니다. 다양한 문자 표시를 위한 폴백이며 모든 글리프·RTL·조합 표시의 실제 화면 검증을 완료했다는 뜻은 아닙니다.
The optional pack uses Noto Fonts revision ffebf8c1ee449e544955a7e813c54f9b73848eac and Noto CJK revision f8d157532fbfaeda587e826d4cd5b21a49186f7c. Its fonts directory includes LICENSE-Noto.txt, LICENSE-Noto-CJK.txt and font-provenance.json; fonts are not sold on their own. They provide multilingual fallback, without claiming that every glyph, RTL or combining sequence has passed actual screen validation.
