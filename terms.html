온말(Onmal)은 선택한 소리를 인식해 번역 자막으로 보여주는 무료 소프트웨어입니다. 이 약관은 온말을 이용할 때의 조건과 사용 제한을 설명합니다.

이 문서는 동봉된 Windows 로컬 처리 버전에 적용됩니다. 다른 배포 버전은 해당 버전의 안내를 확인해 주세요.

1. 제공하는 기능

온말은 이용자의 컴퓨터에 설치해 사용합니다. 지원 운영체제와 기능, 모델 및 언어는 설치한 버전에 따라 다릅니다. 앱의 안내와 공식 홈페이지에서 실제 제공 범위를 확인해 주세요. 개발 중인 기능이나 다른 운영체제의 기능이 모두 제공된다는 뜻은 아닙니다.

기본 음성 인식과 동봉 번역 모델의 처리는 이용자의 컴퓨터에서 이루어집니다. 온말 자체 회원가입이나 별도의 번역 중계 서버는 두지 않습니다. 다만 Steam 통신과 모델·팩 다운로드는 로컬 추론과 별개입니다.

수신 음성 자막, 직접 입력한 글의 번역, 번역 음성 듣기는 해당 기능이 제공되는 버전에서 사용할 수 있습니다. 읽어주기는 이용자가 직접 켰을 때만 선택한 출력 장치에서 재생합니다. 설치된 운영체제 음성이나 이용 조건을 확인한 로컬 음성 모델을 사용하며, 지원하는 언어와 음성은 제한됩니다. 안전하게 입력과 출력을 분리할 수 없는 경로에서는 읽어주기를 제한할 수 있습니다.

앱·장치 캡처 경로는 마이크 한 문장 송신이나 Alt+M 송신 기능을 제공하지 않습니다. 텍스트 결과는 이용자가 명시적으로 복사할 수 있으며, 다른 앱에 붙여넣는 작업은 직접 해야 합니다. 온말이 게임 창에 대신 입력하지 않습니다.

Steam 친구·비공개 음성방 기능이 제공되는 버전에서는 이용자가 선택한 친구와 연결할 수 있습니다. 초대·참여와 음성 송수신은 각각 이용자의 선택에 따릅니다. 송수신 동의와 PTT로 허용한 음성은 Steam 네트워크를 통해 방 참가자에게 전송됩니다. 통화 통역을 별도로 켜면 인식·번역은 로컬 모델로 처리합니다. 이 통화 통역 경로는 클라우드 음성 인식·번역 API를 사용하지 않습니다.

통화 자막은 메모리에 최근 100개까지 표시하며, 자동 녹음이나 전사 파일 저장은 하지 않습니다. 통화 읽어주기를 제공하는 경우에도 수신자가 직접 켠 기기에서만 재생하고, 합성 음성을 상대방에게 다시 송신하지 않습니다.

앱 실행이나 첫 설정 완료, 음성방 입장만으로 음성을 수집·송신하거나 통역 모델을 준비하지 않습니다. 앱·장치 캡처는 시작 버튼 또는 시작·정지 단축키를 직접 실행해야 시작합니다. 자막 숨기기는 처리 정지와 다릅니다.

새 자막 파일 기록은 제공하지 않으며 이전 기록 파일도 자동 삭제하지 않습니다. 일반 Windows 앱·오류 로그와 선택 진단 기록은 자막 기록과 구분합니다. 처리·저장·외부 전송·삭제에 관한 자세한 내용은 개인정보 처리방침을 확인해 주세요.

2. 이용 허락

온말 본체는 무료로 제공하며 개인적 용도와 상업적 용도로 사용할 수 있습니다.

다음 행위는 허용하지 않습니다.

  • 온말을 되팔거나 유료로 재배포하는 행위
  • 온말의 이름·로고를 사용한 파생 제품을 배포하는 행위
  • 온말을 개조해 제3조의 이용 제한을 우회하는 행위

오픈소스 구성요소와 모델에 별도 라이선스가 적용되는 경우 해당 조건도 확인해야 합니다.

3. 대화와 게임에서의 사용

참여 중인 대화에서 사용하기

온말은 이용자 본인이 참여하고 있는 음성 채널에서만 사용해야 합니다. 상대방에게 음성 처리 사실을 알리고, 필요한 동의와 이용 권한을 확인해 주세요.

다음 용도로 사용할 수 없습니다.

  • 자신이 참여하지 않은 타인 간 대화를 청취하거나 기록하는 행위
  • 상대방이 알지 못하는 상태에서 대화를 몰래 수집하는 행위
  • 수집한 내용을 당사자의 동의 없이 공개하거나 배포하는 행위

대한민국의 통신비밀보호법은 법률에 따른 예외를 제외하고 공개되지 않은 타인 간 대화를 녹음하거나 청취하는 행위를 금지합니다. 다른 지역에도 관련 법률이 있으며 모든 참여자의 동의를 요구하는 경우가 있습니다. 적용되는 법률과 대화 참여자의 권리를 확인해야 합니다.

이 제한을 위반해 발생한 이용자의 법적 책임은 이용자가 부담합니다. 이 조항은 관계 법령에 따른 이용자의 권리나 제8조의 책임 제한 예외를 없애지 않습니다.

게임과 안티치트 정책

온말은 게임 프로세스에 코드를 주입하거나 게임 메모리를 읽거나 그래픽 API를 후킹하지 않습니다. 자막은 게임과 독립된 별도 창에 표시합니다.

게임과 안티치트 제공사의 정책은 온말이 통제하지 않습니다. 해당 게임에서 사용할 수 있는지는 게임 이용약관을 확인해 주세요. 독립 자막창이라는 이유만으로 모든 게임·전체화면에서의 표시, 호환성이나 제재가 없음을 보장하지 않습니다.

4. AI가 만든 자막과 그 한계

온말의 자막은 인공지능(AI) 음성 인식 모델과 기계 번역 모델이 자동으로 만든 결과입니다. 사람이 확인하거나 고친 내용이 아닙니다. 앱의 첫 실행 안내와 자막 화면에도 이 사실을 표시합니다.

음성 인식과 번역에는 오류가 있을 수 있습니다. 소음·억양·사투리·마이크 품질, 겹쳐 말하기, 출력 장치 변경과 혼합 오디오는 결과에 영향을 줍니다. 자동 언어 감지, 문맥·은어·게임 용어 해석도 틀릴 수 있습니다.

앱별 캡처는 같은 게임 안의 팀원 음성과 효과음을 자동으로 분리하지 않습니다. UI 표시 언어, 인식 언어, 번역 언어, 읽어주기 언어와 실제 품질 검증 범위는 서로 다릅니다. 선택 목록에 보이거나 모델이 언어를 지원한다는 사실만으로 해당 언어의 품질 검증이 끝났다는 뜻은 아닙니다.

인식·번역 결과를 다음 용도로 사용해서는 안 됩니다.

  • 의료·법률·금융 등 중대한 결정의 근거
  • 공식 기록이나 증거
  • 안전에 관련된 판단

온말은 게임 이용을 돕는 보조 도구입니다. 결과가 중요한 상황에서는 원래 내용을 직접 확인해 주세요.

5. 사용 환경과 테스트 버전

Windows 제품의 대상은 Windows 11 x64입니다. Windows 10을 현재 지원 운영체제로 안내하지 않습니다. 동봉 Windows 네이티브 엔진은 AVX·AVX2·FMA·F16C와 Visual C++ 2022 x64 실행 환경을 요구합니다. macOS의 지원 버전·칩과 제공 기능은 별도 설치 안내를 따릅니다.

자막의 기본 대상은 창 모드와 테두리 없는 창 모드입니다. 독점 전체화면에서 자막이 표시된다고 보장하거나 게임 후킹으로 우회하지 않습니다. 게임·모니터·배율·안티치트에 따른 동작은 달라질 수 있습니다.

선택한 앱이나 장치에 어떤 소리가 포함되는지 확인해 주세요. 기본 모델이 정상 설치되어 있으면 그 모델의 기본 처리에 매번 추가 다운로드가 필요한 것은 아닙니다. Steam 설치·업데이트, 빠진 모델이나 선택 팩·글꼴의 다운로드에는 네트워크가 필요할 수 있습니다.

Playtest는 개발 중인 테스트 버전이며 본편 정식 출시와 구분합니다. 설치·재시작·자막·음성·게임 동시 실행과 저사양 성능이 모든 환경에서 검증되었다고 보장하지 않습니다. 두 PC 통화, 음질, 최고 품질 지연 및 게임 성능의 검증 여부는 해당 빌드 안내를 확인해 주세요.

모델과 품질 선택은 이용자의 설정을 따릅니다. 최고 품질은 메모리 사용량과 처리 시간이 늘어날 수 있습니다. 권장 모드 안내가 표시되어도 이용자의 최고 품질 선택을 자동으로 낮추지 않습니다.

6. 개인 API 기능과 이전 설정

이 버전에서는 개인 API 키 입력·연결 확인·번역 요청을 제공하지 않습니다. 앱에서 키를 저장·조회·삭제하는 화면도 제공하지 않습니다.

이전 버전에서 저장한 API 선호와 보호된 키가 기기에 남아 있을 수 있으며, 이 버전은 이를 자동 삭제하지 않습니다. 기기에 남은 키 데이터와 제공사 계정의 키 폐기는 서로 다릅니다. 자세한 내용은 개인정보 처리방침을 확인해 주세요.

  • 키 유출·오용으로 인한 손해에는 제8조와 관계 법령의 범위에서 책임을 제한합니다. 개발자의 고의·중대한 과실이나 법령상 배제할 수 없는 책임까지 면제하지 않습니다.

7. 무료 제공

온말 본체의 기능은 무료입니다. 온말은 무료·비수익 조건을 유지하며 광고·결제·구독·후원·유료 DLC를 추가하지 않습니다.

8. 책임의 범위

온말은 있는 그대로 제공됩니다. 법이 허용하는 범위에서 번역 오류, 게임 내 불이익이나 계정 제재, 데이터 손실, 다른 소프트웨어와의 충돌로 인한 책임을 제한합니다.

법이 허용하는 범위에서 온말의 책임 한도는 이용자가 온말에 지급한 금액이며, 무료 본체의 경우 0원입니다.

다만 개발자의 고의 또는 중대한 과실로 이용자에게 손해가 발생한 경우에는 위 면책과 한도를 적용하지 않습니다. 대한민국 약관의 규제에 관한 법률 등 관계 법령에 따라 배제하거나 제한할 수 없는 책임에도 위 제한을 적용하지 않습니다. 이용자가 소비자로서 관계 법령에 따라 갖는 권리는 이 약관으로 제한하지 않습니다.

9. 저작권과 라이선스

온말은 오픈소스 소프트웨어와 모델을 사용합니다. 구성요소, 저작권자와 적용 조건은 동봉된 THIRD_PARTY_NOTICES.md 및 앱의 안내 탭에서 확인할 수 있습니다.

로컬 음성 모델을 포함한 각 모델의 이용 조건은 별도로 적용됩니다. 온말 본체의 무료 이용 허락이 제3자 구성요소·모델의 조건을 대신하지 않습니다.

온말은 위 회사와 제휴·후원·보증 관계가 없습니다. 이름과 게임 용어는 함께 사용하는 환경과 용어의 뜻을 설명하기 위해 언급합니다. 온말의 이용 허락은 이들 회사의 로고·서체·이미지 사용 권한을 부여하지 않습니다.

온말의 제공은 중단될 수 있습니다. 별도 Steam Playtest의 참가·다운로드·실행 가능 상태는 Steam 운영 설정에 따라 달라질 수 있으며, 설치 후 계속 실행할 수 있음을 보장하지 않습니다. Playtest의 이용 가능 상태 변경과 본편 정식 출시는 별개의 절차입니다. 관계 법령에 따른 이용자 권리는 그대로 적용됩니다.
