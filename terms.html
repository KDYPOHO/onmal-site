이용약관

기존 문서 표시: 최종 갱신 2026-08-06 · 적용 버전 0.1.0

사실 안내 갱신 2026-10-20 · Windows 0.3.2 후보 · 효력일 변경 아님

이 문서는 한국어가 정본입니다 · The Korean text is authoritative

출시 전 안내입니다. Windows 0.3.2의 Playtest·본편 후보는 업로드됐으나 정식 출시는 보류 중입니다. 2026-10-20 17:22 KST 확인 기준 Playtest는 미활성이며, 상점 승인과 빌드 승인은 별개입니다. 법률 검토는 완료되지 않았습니다. 이번 갱신은 제품·처리·배포 사실의 정정이며, 이용 허락·이용 제한·책임/면책·변경/종료·준거법 조항의 유효성이나 적합성을 새로 승인하는 것이 아닙니다. 기존 소비자 권리·고의/중과실 보호 문구는 유지합니다. 설치된 앱과 기존 Steam 제출물의 문서 교체를 뜻하지 않습니다.

1. 온말은 무엇인가

온말은 게임 중 음성 채팅의 말을 인식해 번역 자막으로 보여주는 Windows용 무료 소프트웨어입니다.

기본 음성 인식·동봉 한영 번역은 이용자의 컴퓨터에서 처리합니다. 개인 API를 선택하면 인식/입력 텍스트가 제공사로 전송됩니다. 모델·팩 다운로드와 Steam 자체 통신은 별도이며, 온말 자체 회원가입·별도 번역 중계 서버는 현재 제품 코드에 없습니다.

Windows 후보는 수신 음성 자막과 직접 입력한 텍스트 번역을 제공합니다. 마이크 한 문장 송신·Alt+M·읽어주기 기능은 제거됐습니다. 텍스트 결과를 명시적으로 복사할 수 있으며, 붙여넣기는 이용자가 수행합니다. 온말이 게임 창에 대신 입력하지 않습니다.

앱 실행·첫 안내 완료만으로 음성 입력을 시작하지 않습니다. 시작 버튼 또는 시작/정지 단축키를 사용해야 합니다. 자막 숨김은 처리 정지와 다릅니다. 자막 파일 기록과 상세 진단은 기본 꺼짐이지만 일반 Windows 앱·오류 로그는 생성됩니다. 저장·전송·키 보호·삭제 범위는 개인정보처리방침의 사실 안내를 함께 확인하십시오.

2. 이용 허락

온말 본체는 무료로 제공되며, 개인적·상업적 용도를 가리지 않고 사용하실 수 있습니다.

다음은 하실 수 없습니다.

  • 온말을 되팔거나 유료로 재배포하는 것
  • 온말의 이름·로고를 사용한 파생 제품을 배포하는 것
  • 온말을 개조해 아래 §3의 제한을 우회하는 것

3. 이용 제한 — 반드시 읽어주세요

참여 중인 대화에서만 사용하십시오.
온말은 이용자 본인이 참여하고 있는 음성 채널에서만 사용해야 합니다.

다음 용도로 사용하는 것을 금지합니다.

  • 자신이 참여하지 않은 타인 간의 대화를 청취·기록하는 것
  • 상대방이 알지 못하는 상태에서 대화를 몰래 수집하는 것
  • 수집한 내용을 당사자의 동의 없이 공개·배포하는 것

법적 고지 — 대한민국 통신비밀보호법은 공개되지 아니한 타인 간의 대화를 당사자가 아닌 제3자가 청취·녹음하는 것을 금지합니다. 다른 국가에도 유사한 법이 있으며, 일부 지역은 모든 참여자의 동의를 요구합니다. 거주 지역의 법을 확인하는 것은 이용자의 책임입니다.

이 제한을 위반해 발생하는 법적 책임은 전적으로 이용자에게 있습니다.

안티치트에 대하여

온말은 게임 프로세스에 코드를 주입하거나, 게임 메모리를 읽거나, 그래픽 API를 후킹하지 않습니다. 자막은 게임과 완전히 독립된 별도의 창으로 표시됩니다.

다만 각 게임과 안티치트 제공사의 정책은 저희가 통제할 수 없습니다. 특정 게임에서의 사용 가능 여부는 해당 게임의 이용약관을 확인하십시오. 독립 자막창 방식이 모든 게임의 호환성·전체화면 가시성·무제재를 보장하는 것은 아닙니다.

4. 번역 정확도에 대한 무보증

온말의 인식·번역 결과는 정확하지 않을 수 있습니다.

  • 음성 인식은 소음, 억양, 마이크 품질에 크게 영향받습니다.
  • 기계 번역은 맥락·은어·게임 용어를 잘못 옮길 수 있습니다.
  • 언어 자동 감지가 틀릴 수 있습니다.
  • 앱별 캡처는 같은 앱의 팀원 음성과 효과음을 자동 분리하지 않습니다. 겹친 말·혼합 오디오·장치 변경이 결과에 영향을 줄 수 있습니다.
  • UI 언어·언어 선택 목록·엔진별 지원과 실제 음성 인식·번역 품질 검증은 서로 다릅니다.

온말의 출력을 다음 용도로 사용해서는 안 됩니다.

  • 의료·법률·금융 등 중대한 결정의 근거
  • 공식 기록이나 증거
  • 안전에 관련된 판단

온말은 게임을 즐기기 위한 보조 도구입니다. 그 이상으로 신뢰하지 마십시오.

5. 동작 조건

현재 검증 대상과 남은 범위를 구분합니다.

  • 현재 제품 후보는 Windows 11 x64 대상입니다. macOS 다운로드를 제공하지 않습니다.
  • 자막창의 기본 검증 범위는 테두리 없는 창 모드 또는 창 모드입니다. 독점 전체화면의 표시를 보장하거나 게임 후킹으로 우회하지 않습니다. 게임·배율·안티치트 환경의 실제 검증은 별도입니다.
  • 앱 또는 출력 장치를 선택해 듣습니다. 같은 앱의 팀원 음성·효과음·대사가 함께 들어올 수 있습니다.
  • 기본 한영 모델은 Steam 후보 배포물에 동봉하도록 구성했습니다. 정상 동봉 상태에서 기본 번역에 추가 다운로드가 필요한 것은 아니지만, Steam 설치·업데이트·선택 모델/팩·개인 API에는 네트워크가 필요할 수 있습니다.
  • 자동 회귀 검사와 Windows 교차 빌드 보고가 실제 Windows의 음성·통역·게임 성능 검증을 대신하지 않습니다. 실제 Windows 설치·실행·품질·성능 검증은 미완료입니다.

6. 이용자의 API 키

이용자가 자신의 API 키를 입력해 클라우드 번역을 사용하는 경우:

  • 해당 제공사에 발생하는 비용은 이용자가 직접 부담합니다.
  • 해당 제공사의 이용약관이 함께 적용됩니다.
  • Windows 키는 현재 사용자 계정 범위 DPAPI로 보호한 값을 설정 파일에 저장합니다. 요청 인증에 사용하는 키와 텍스트는 해당 제공사로 직접 전송됩니다. 현재 API 번역 경로는 음성 파일을 보내지 않습니다.
  • 키 유출·오용으로 인한 손해에 대해 저희는 책임지지 않습니다.

7. 현재 무료·비수익 운영

현재 온말에는 유료 요소가 없습니다. 현재 운영 방향은 무료·비수익이며 광고·결제·구독·후원·유료 DLC를 두지 않습니다.

사용자가 선택한 외부 API 제공사의 이용 요금은 온말의 결제·구독과 별개입니다.

8. 책임의 한계

온말은 있는 그대로(as-is) 제공됩니다.

법이 허용하는 최대 범위에서, 다음에 대해 책임지지 않습니다.

  • 번역 오류로 인한 손해
  • 게임 내 불이익 (패배, 계정 제재 등)
  • 데이터 손실
  • 다른 소프트웨어와의 충돌

온말은 무료로 제공되므로, 책임 범위는 이용자가 온말에 지불한 금액 (무료 본체의 경우 0원)을 넘지 않습니다.

다만 다음은 위 제한의 예외입니다. 대한민국 약관의 규제에 관한 법률 제7조제1호는 고의 또는 중대한 과실로 인한 법률상의 책임을 배제하는 조항을 무효로 합니다. 따라서 저희의 고의 또는 중대한 과실로 이용자에게 손해가 발생한 경우 위 면책과 한도는 적용되지 않습니다. 이용자가 소비자로서 관계 법령에 따라 갖는 권리도 이 약관으로 제한되지 않습니다.

9. 저작권 및 라이선스

온말은 여러 오픈소스 소프트웨어와 모델을 사용합니다. 전체 목록과 라이선스는 저작권 및 라이선스 및 앱 내 정보 → 저작권 및 라이선스에서 확인하실 수 있습니다.

10. 상표

Steam은 Valve Corporation, Discord는 Discord Inc., Windows는 Microsoft Corporation의 상표입니다.

온말에 동봉된 용어집은 여러 게임에서 쓰이는 말을 다룹니다. 발로란트(VALORANT)는 Riot Games, Inc., 배틀그라운드(PUBG: BATTLEGROUNDS)는 크래프톤 주식회사, 에이펙스 레전드(Apex Legends)는 Electronic Arts Inc., 오버워치(Overwatch)는 Blizzard Entertainment, Inc.의 상표이며, 그 밖에 언급되는 모든 상표는 각 소유자의 재산입니다.

온말은 위 어느 회사와도 제휴·후원·보증 관계가 없습니다. 이름을 사용하는 것은 오로지 온말이 무엇과 함께 동작하는지, 어떤 말을 알아듣는지를 설명하기 위해서입니다. 온말은 이들 회사의 로고·서체·이미지를 사용하지 않습니다.

11. 변경 및 종료

이 약관이 바뀌면 앱 내 공지와 이 페이지에 게시합니다. 저희는 온말의 제공을 중단할 수 있으나, 이미 설치된 소프트웨어를 원격으로 비활성화하지는 않습니다.

12. 준거법
