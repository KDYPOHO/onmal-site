말이 끝나기도 전에 자막이 올라옵니다.

네 단계가 사용자 PC 안에서 이어집니다. 서버를 거치지 않으니 왕복 지연이 없고, 인터넷이 끊겨도 계속 동작합니다.

01 · 듣기

Discord 소리만 골라서

Windows의 프로세스 단위 오디오 캡처를 씁니다. 게임 총성과 BGM은 들어오지 않습니다.

02 · 자르기

말할 때만 반응

발화 감지가 사람 목소리 구간만 잘라냅니다. 조용할 땐 아무 일도 하지 않습니다.

03 · 알아듣기

무슨 언어인지 알아서

언어를 미리 지정할 필요가 없습니다. 러시아어든 포르투갈어든 감지해서 받아씁니다.

04 · 옮기기

내 언어로 화면 위에

게임을 가리지 않는 자리에, 클릭이 통과하는 자막으로. 조작을 방해하지 않습니다.

비서처럼

켜두면, 잊고 있어도 일합니다.

설정은 처음 한 번

소리를 가져올 앱과 내 언어만 고르면 끝입니다. 그 뒤로는 게임만 켜면 됩니다.

내 API 키를 넣어도 됩니다

기본 번역은 무료로 내장돼 있습니다. 더 정확한 번역이 필요하면 본인의 API 키를 넣어 쓸 수 있습니다. 키는 이 컴퓨터에만 암호화되어 저장됩니다.

대화가 밖으로 나가지 않습니다

음성은 메모리에서 처리하고 버립니다. 기본 설정에서는 녹음도, 업로드도, 계정도 없습니다.

먼저 알려드립니다

못 하는 것도 적어둡니다.

설치하고 나서 알게 되는 것보다, 지금 아는 편이 낫습니다.

독점 전체화면에서는 안 보입니다

게임을 '테두리 없는 창 모드' 또는 '창 모드'로 실행해야 자막이 화면 위에 올라옵니다. 대부분의 게임이 설정에서 바꿀 수 있습니다.

앱별 소리 분리는 Windows 11부터

Discord 소리만 골라 듣는 기능은 Windows 11(또는 Windows 10 빌드 20348 이상)에서 동작합니다. 그 이하에서는 시스템 소리 전체를 받습니다.

완벽한 번역은 아닙니다

총성과 고함이 섞인 음성은 사람도 못 알아듣습니다. 온말도 마찬가지입니다. 틀렸을 때는 틀렸다고 표시합니다.

게임을 건드리지 않습니다

게임 프로세스에 어떤 코드도 주입하지 않습니다. 안티치트에 걸릴 만한 동작을 하지 않는다는 뜻이고, 대신 위의 창 모드 제약이 생깁니다.

Steam 및 Steam 로고는 Valve Corporation의 상표입니다. Discord는 Discord Inc.의 상표입니다. 온말은 해당 기업과 제휴 관계가 없으며, 호환성을 설명하기 위해 명칭을 사용합니다.
