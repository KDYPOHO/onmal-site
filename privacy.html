한 줄 요약 — 온말은 서버가 없습니다.
모든 처리는 사용자의 PC 안에서 일어나고, 기본 설정에서 어떤 데이터도 외부로 나가지 않습니다.

이 문서는 v1.0 출시 전 문서입니다. 내용이 바뀌면 이 페이지와 앱 내 공지로 알립니다. 같은 문서가 앱 안(정보 → 개인정보처리방침)에도 들어 있습니다.

1. 온말이 처리하는 것

음성

온말은 사용자가 지정한 앱(예: Discord)의 소리를 캡처해 텍스트로 변환합니다. 여기에는 다른 사람(팀원)의 음성이 포함됩니다.

저장 여부저장하지 않습니다. 메모리에서 처리하고 즉시 폐기합니다.
전송 여부전송하지 않습니다. (단, 아래 §3의 본인 API 키 사용 시 예외)
보관 기간없음. 처리 직후 메모리에서 지웁니다.

마이크 (선택 — 기본 꺼짐)

온말의 본체는 팀원의 목소리를 듣는 것이지만, 설정에서 내 말을 팀원 언어로 옮겨 보내기를 켜면 반대 방향도 씁니다. 이때만 마이크가 열립니다.

기본값꺼져 있음. 켜지 않으면 마이크를 여는 코드 자체가 실행되지 않습니다.
여는 시점단축키를 누른 순간부터 한 문장이 끝날 때까지만. 말이 없으면 15초 뒤 스스로 닫힙니다.
저장 여부저장하지 않습니다. 팀원 음성과 같은 경로로 메모리에서 처리하고 폐기합니다.
전송 여부전송하지 않습니다. 인식도 번역도 이 컴퓨터 안에서 끝납니다 (아래 §3의 본인 API 키 사용 시 예외).
결과물옮긴 한 문장이 클립보드에 담깁니다. 클립보드는 이 컴퓨터의 다른 앱도 읽을 수 있는 공용 공간입니다. 게임 채팅에 붙여넣는 것은 이용자 본인이며, 온말이 게임 창에 대신 입력하지 않습니다.
소리 출력없습니다. 옮긴 문장을 소리로 내보내는 기능은 2026-08-02에 제거했습니다. 결과는 클립보드 하나뿐입니다.

인식·번역 결과 텍스트

화면에 자막으로 표시된 뒤 사라집니다. 기본 설정에서는 디스크에 남지 않습니다.

사용자가 설정에서 명시적으로 켠 경우에만 자막 기록이 이 컴퓨터의 로컬 파일 (%LOCALAPPDATA%\Onmal\subtitles)에 저장됩니다. 이 파일은 어디로도 전송되지 않습니다.

설정값

선택한 오디오 소스, 언어, 자막 크기·위치 등입니다. %LOCALAPPDATA%\Onmal\settings.json 에 저장되며 이 컴퓨터를 벗어나지 않습니다.

API 키 (선택)

사용자가 직접 입력한 경우에만 존재합니다. Windows DPAPI로 암호화되어 저장되며, 같은 Windows 사용자 계정에서만 복호화할 수 있습니다. 설정 파일을 다른 PC로 복사해도 키는 풀리지 않습니다. 평문으로 저장하거나 로그에 남기지 않습니다.

2. 온말이 수집하지 않는 것

명시적으로 나열합니다.

  • 계정 정보 (온말은 회원가입이 없습니다)
  • 이메일 주소, 이름, 전화번호
  • IP 주소
  • 기기 식별자, 하드웨어 지문
  • 사용 통계, 광고 식별자
  • 게임 플레이 데이터
  • 음성 녹음 파일
  • 자막·대화 내용

온말에는 분석 도구(Analytics)가 들어 있지 않습니다.

3. 외부로 데이터가 나가는 유일한 경우

사용자가 자신의 API 키를 입력했을 때

더 정확한 번역을 원하는 사용자는 OpenAI, Google, Anthropic, DeepL 중 하나의 자기 API 키를 입력할 수 있습니다. 이 경우 인식된 텍스트가 해당 제공사로 직접 전송됩니다.

기본값꺼져 있음. 사용자가 켜야 동작합니다.
전송되는 것인식된 텍스트(원문)와 번역 지시문
전송되지 않는 것음성 데이터, 설정, 식별자
경유지없음. 사용자 PC → 제공사. 온말의 서버를 거치지 않습니다.
표시설정 화면에 전송 대상 호스트를 항상 보여줍니다.

전송된 데이터의 처리는 각 제공사의 방침을 따릅니다 — OpenAI · Google · Anthropic · DeepL

모델 다운로드

최초 실행 시 음성 인식 모델을 내려받습니다. 이때 배포처(Hugging Face)에 표준적인 HTTP 요청이 발생하며, 여기에는 사용자를 식별하는 정보가 포함되지 않습니다.

크래시 리포트 — 없습니다

온말에는 크래시 리포트를 전송하는 기능 자체가 없습니다. 오류 기록은 이 컴퓨터의 로그 파일(%LOCALAPPDATA%\Onmal\logs)에만 남으며, 문의 시 이용자가 직접 첨부하지 않는 한 저희가 볼 방법이 없습니다.

4. 다른 사람의 음성에 대하여

온말은 사용자 본인뿐 아니라 같은 음성 채널에 있는 다른 사람의 말을 처리합니다. 이 점을 분명히 밝히고, 다음을 설계에 반영했습니다.

  • 첫 실행 시 "팀원의 음성이 처리됩니다"를 고지하고 동의를 받습니다.
  • 음성을 저장하지 않아 녹음물 자체가 생기지 않습니다.
  • 사용자가 참여 중인 음성 채널에서만 사용하도록 이용약관에 명시합니다.

이용자 책임 — 참여하지 않은 대화를 몰래 듣는 용도로 온말을 사용하는 것은 이용약관 위반이며, 거주 국가의 법(대한민국의 경우 통신비밀보호법)에 저촉될 수 있습니다.

5. 이용자의 권리

모든 데이터가 이용자 본인의 컴퓨터에만 있으므로, 다음을 직접 하실 수 있습니다.

열람%LOCALAPPDATA%\Onmal 폴더를 여십시오
삭제해당 폴더를 지우면 모든 설정과 기록이 사라집니다
API 키 삭제홈 → 제공사 선택 → [삭제]
처리 중지앱을 종료하거나 Alt+P로 일시정지

온말은 이용자 데이터를 보유하고 있지 않으므로, 저희에게 삭제를 요청하실 대상이 없습니다.

GDPR / 개인정보 보호법

로컬 처리 원칙에 따라 개인정보의 수집·이전이 발생하지 않습니다. 본인 API 키를 사용하는 경우, 해당 제공사와 이용자 사이의 관계가 되며 온말은 처리자가 아닙니다.

6. 아동

온말은 아동을 대상으로 하지 않으며, 아동 대상 기능이 없습니다. Steam의 연령 정책을 따릅니다.

7. 변경

이 방침이 바뀌면 앱 내 공지와 이 페이지에 게시합니다. 데이터 처리 방식에 실질적인 변경이 있는 경우, 변경 전에 앱 내에서 알립니다.
