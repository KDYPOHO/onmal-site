1. 음성 처리의 시작과 중지

온말은 선택한 앱 또는 장치의 소리를 인식해 번역 자막으로 표시합니다. 입력에 팀원의 음성뿐 아니라 같은 앱의 효과음과 대사가 섞일 수 있습니다.

앱 실행, 설정 준비, 첫 실행 안내나 약관 확인만으로 음성을 수집하지 않습니다. 앱·장치 캡처는 시작 버튼 또는 시작·정지 단축키를 직접 실행해야 시작합니다. 단축키는 운영체제와 이용자 설정에 따라 다르며 다른 앱과 충돌할 수 있습니다. Windows의 기본 시작·정지 단축키는 Alt+Shift+P입니다.

자막 숨기기는 처리 정지가 아닙니다. 입력 처리를 멈추려면 정지하거나 앱을 완전히 종료해 주세요. 앱·장치 캡처 경로에는 마이크 한 문장 송신이나 Alt+M 송신 기능을 제공하지 않습니다.

직접 입력한 글의 번역, Steam 음성방, 번역 음성 듣기는 해당 기능을 제공하는 버전에서만 사용할 수 있습니다. 개발 중인 기능이나 다른 운영체제의 기능이 모두 제공된다는 뜻은 아닙니다.

2. 기기에서 처리하거나 저장하는 정보

소리와 자막

선택한 입력 소리는 메모리에서 음성 인식과 번역에 사용합니다. 인식과 번역은 이용자의 기기에 설치된 인공지능(AI) 모델이 처리하며, 자막은 그 모델이 자동으로 만든 결과입니다. 기본 원음 파일 저장 기능은 제공하지 않습니다. 인식·번역 결과와 입력 텍스트는 자막 표시와 메모리 캐시에 사용합니다.

현재 버전은 자막 파일 기록 기능을 제공하지 않습니다. 이전 설정에 기록이 켜져 있어도 새 파일을 만들거나 기존 자막 파일에 추가하지 않습니다. 메모리 버퍼와 추론 중간값·캐시는 사용하며, 모든 복사본을 처리 직후 즉시 완전 삭제한다고 보장하지 않습니다.

통화 기능이 제공되는 버전의 통화 자막은 메모리에 최근 100개까지 표시합니다. 자동 녹음이나 전사 파일 저장은 하지 않습니다.

이전 버전의 자막 파일

이전 Windows 버전에서 기록을 켰다면 시각·언어쌍·원문·번역문이 담긴 TXT 파일이 남아 있을 수 있습니다. 기본 위치는 %LOCALAPPDATA%\Onmal\subtitles\subtitles-YYYY-MM-DD.txt입니다.

현재 버전은 이 파일을 열거나 수정·삭제하지 않습니다. 이용자가 직접 삭제할 때까지 남을 수 있으며 자동 보관 기한은 없습니다.

일반 앱·오류 로그

Windows에서는 시작·종료, 상태, 모델·런타임, 실패에 관한 운영 정보를 %LOCALAPPDATA%\Onmal\logs에 저장합니다. 예외 정보나 장치·파일 경로가 포함될 수 있습니다.

기본 Information 로그가 있으며 시작 시 7일 보관 정리를 시도합니다. 파일 접근 제한이나 삭제 실패가 생길 수 있어 정리가 항상 성공한다고 보장하지 않습니다. 일반 로그와 자막 파일은 다릅니다.

상세 진단 로그

상세 진단에는 처리 시간, 큐 누락, 인식 판정의 길이·확률·언어 같은 값을 사용합니다. 발화 내용과 API 키를 일반·진단 로그에 기록하지 않도록 구현합니다.

Windows 일반 로그와 같은 폴더를 사용하며 기본값은 꺼짐입니다. 이전 진단 설정이나 개발용 로그 수준 설정이 적용될 수 있습니다. 해당 설정이 제공되는 버전에서만 사용할 수 있습니다.

선택한 로컬 테스트 기록

로컬 테스트 기록은 해당 기능이 있는 Windows·macOS 버전의 통역 준비 화면에서 이용자가 켰을 때만 남깁니다. 기본값은 꺼짐입니다. 통역을 시작한 세션의 메타데이터와 이용자가 직접 시작한 자동 진단의 최근 결과를 구분해 저장합니다.

기록에는 앱 버전, 허용된 모델 ID와 확인한 해시, 입력 종류, 정규화 처리 형식, 허용 언어 코드, VAD 구간과 처리·발행 시간, 상태·오류 코드를 사용합니다. 확인하지 못한 실제 입력 형식이나 값은 미상으로 표시합니다.

대화·자막·번역문·오디오·API 키·계정 정보·이용자 경로·앱이나 장치의 이름과 ID·프로세스 ID·예외 본문은 이 기록에 넣지 않습니다.

Windows의 기본 위치는 %LOCALAPPDATA%\Onmal\test-sessions-v1, macOS는 ~/Library/Application Support/Onmal/test-sessions-v1이며 버전이 지정된 JSON 형식을 사용합니다. 통역 세션당 최대 256 KiB·2,048개 관측을 남깁니다. macOS는 최근 자동 진단 1개·16 KiB를 포함해 자체 기록 전체를 최대 12개·2 MiB로 제한합니다. 진단 결과에는 완료 시각, 앱 버전, 품질, 모델·언어 선택과 단계별 상태·사유·다음 조치만 들어갑니다. 이 기능이 검증한 자체 기록만 오래된 순으로 정리합니다.

통역을 중지하거나 기록 기능을 끄거나 정상 종료하면 완료 기록을 원자적으로 저장합니다. 자동 진단은 작업을 마친 뒤에도 기록 선택이 유지되어 있을 때 최근 결과만 저장합니다. 비정상 종료 중인 미완료 세션의 복구를 보장하지 않습니다. 통역 준비에서 최근 완료 기록을 보거나 JSON 사본을 저장하고 자체 기록을 삭제할 수 있습니다. 통역 기록과 자동 진단 결과의 파일 형식은 구분합니다. 사본 저장은 선택한 위치에 파일을 만들 뿐 개발자에게 보내지 않습니다. 자동 전송이나 동기화는 하지 않습니다.

검증용 설치본은 일반 제품 데이터와 분리된 검증 버전별 저장 폴더를 사용할 수 있습니다. 실제 저장 위치와 삭제 범위를 확인한 뒤 공유하거나 삭제해 주세요.

설정과 모델·팩

설정에는 선택 앱 실행 파일명, 게임 경로, 출력·모니터 장치 ID, 언어, 자막 모양 등이 포함될 수 있습니다. Windows의 기본 설정 파일은 %LOCALAPPDATA%\Onmal\settings.json입니다. 저장한 설정은 재실행 시 다시 사용합니다. 이전 자막 기록 값은 꺼짐으로 처리하고 다음 저장에도 꺼짐을 씁니다. 이전 버전의 API 선호와 보호된 키 데이터가 설정에 남아 있을 수 있으며, 이 버전은 이를 자동 삭제하지 않습니다.

macOS에서는 네이티브 화면과 로컬 worker가 파이프로 명령·음성·텍스트를 교환하며, 설정은 기기의 앱 데이터 경로에 저장합니다. Windows 일반 파일 로그와 동일한 방식을 그대로 사용하지 않습니다. macOS에서도 자막 파일 기록을 켜지 않으며 이전 파일을 자동 삭제하지 않습니다.

추가로 내려받은 모델·팩과 포함 글꼴은 이용자의 모델·팩 폴더에 남습니다. 앱 제거와 함께 모두 삭제된다고 가정하지 말고 실제 설치 위치를 확인해 주세요.

약관 확인 기록

최초 동의 저장 기능이 적용된 버전에서는 이용자가 직접 확인한 필수 약관 버전, 해당 문서의 SHA-256, 동의한 시각(UTC), 동의 항목과 기록 형식 버전을 기기에 저장합니다. 이름·계정·장치 ID·음성·자막·API 키는 이 기록에 넣지 않습니다.

이 기록은 로컬의 약관 확인 이력입니다. 신원 확인이나 변조 방지 전자서명으로 보증하지 않습니다. 운영체제 권한이나 상대방의 동의를 대신하지 않으며 Steam Cloud 동기화에 포함하지 않습니다. 이 기능이 아직 적용되지 않은 버전이 동의 기록을 이미 저장한 것으로 보아서는 안 됩니다.

3. 번역 음성 듣기

읽어주기 기능이 제공되는 버전에서는 이용자가 직접 켰을 때 번역 결과를 선택한 출력 장치에서 재생합니다. 설치된 운영체제 음성이나 이용 조건을 확인한 로컬 음성 모델을 사용하며 지원 언어·음성은 방식에 따라 제한됩니다.

Windows 앱별 캡처의 읽어주기는 다른 앱을 선택한 안전한 ProcessLoopback 입력에서만 허용합니다. 팀원 소리 듣기와 같은 선택 출력 장치로 재생합니다. 입력과 출력을 안전하게 분리할 수 없는 경로에서는 읽어주기가 차단될 수 있습니다.

합성 음성은 메모리에서 처리하고 음성 파일을 만들지 않습니다. 수신자 기기에서만 재생하며 Steam 상대방에게 합성 음성을 다시 송신하지 않습니다. 모든 언어에서 읽어주기를 제공한다는 뜻은 아닙니다. macOS 개발용 버전의 출력 구현과 실제 장치 동작은 Windows와 같다고 가정하지 마세요.

텍스트 결과를 직접 복사하면 운영체제 클립보드에 들어갑니다. 다른 앱의 접근과 운영체제의 클립보드 기록·동기화 설정은 별도로 적용될 수 있습니다.

4. 이전 버전의 API 설정과 키

이 버전에서는 개인 API 키 입력·연결 확인·번역 요청을 제공하지 않습니다. 앱에서 키를 저장·조회·삭제하는 화면도 제공하지 않습니다.

이전 버전의 API 선호와 보호된 키 데이터가 설정에 남아 있을 수 있으며, 이 버전은 이를 자동 삭제하지 않습니다. 설정을 불러오거나 저장할 때 이전 보호키 데이터도 함께 처리될 수 있습니다. 이 데이터가 남아 있다는 이유로 개인 API를 연결하거나 키를 검증·전송하지 않습니다.

Windows에서 저장된 이전 키는 사용자 계정 범위의 DPAPI로 보호된 형태로 설정 파일에 남아 있을 수 있습니다. 해당 Windows 계정과 환경에 연결된 보호이며, PC 복사·운영체제 백업·계정 침해 등 모든 상황의 안전성을 보장하지 않습니다.

이전에 macOS 버전에서 저장한 키는 해당 기기의 Keychain에 남아 있을 수 있습니다. 설정 폴더만 삭제해도 macOS Keychain이나 제공사 계정의 키까지 폐기되는 것은 아닙니다. 제공사 측 키 폐기는 해당 계정에서 별도로 처리해 주세요.

평문 키를 프로세스 실행 인수나 로그에 넣지 않도록 구현합니다.

5. 기기 밖으로 이루어지는 통신

Steam 친구와 음성방

이 기능이 제공되는 버전에서는 Steam 친구와 비공개 방을 이용합니다. 참가자가 명시적으로 송수신에 동의하고 PTT로 허용한 음성이 Steam 네트워크를 통해 방의 상대 참가자에게 전달됩니다.

앱 실행이나 방 입장만으로 음성을 송신하거나 통역 모델을 준비하지 않습니다. Steam SDK 인증·암호화 경로에 관한 구현과 실제 두 PC 통화 검증은 다릅니다. 실제 통화·음질 검증 범위는 해당 빌드 안내를 확인해 주세요.

통화 통역을 별도로 켜면 수신 음성의 인식·번역은 기기의 로컬 모델로 처리하며 이 경로는 음성 인식·번역용 클라우드 API를 사용하지 않습니다. 음성의 네트워크 전송과 통역의 로컬 처리는 별개의 기능입니다. 통화 음성을 Steam Cloud에 저장·동기화하지 않습니다.

클라우드 음성 인식 (선택, 기본 꺼짐)

0.2.6부터 설정의 성능 항목에 클라우드 음성 인식(실험) 스위치가 있습니다. 기본은 꺼져 있으며, 켤 때마다 무엇이 어디로 가는지 알리는 창에서 따로 동의해야 켜집니다. 동의하지 않거나 끄면 지금까지처럼 모든 인식을 PC에서 합니다.

  • 보내는 것: 말이 끝난 구간(0.4~15초)의 소리만 16kHz 소리 파일로 보냅니다. 말하는 도중의 미리보기 자막과 번역은 계속 PC에서 처리합니다. 선택한 입력에 팀원 목소리나 게임 소리가 섞여 있으면 함께 전송됩니다.
  • 받는 곳: 개발자가 운영하는 Cloudflare Workers 중간 서버가 받아 Cloudflare Workers AI의 음성 인식 모델(whisper-large-v3-turbo)로 글자를 만든 뒤 앱으로 돌려줍니다. 앱에는 API 키가 없습니다.
  • 이용자 확인: Steam 웹 API 인증 티켓으로 온말 Playtest 이용자인지만 확인합니다. Steam 계정 번호는 그대로 저장하지 않고, 복원할 수 없게 바꾼 값(해시)으로 하루 사용 시간만 셉니다.
  • 저장하지 않는 것: 소리와 인식된 글자는 처리하는 동안에만 메모리에 있고, 서버에 저장하거나 로그로 남기지 않습니다. Cloudflare Workers AI는 이 모델의 입력을 보관하지 않는다고 밝히고 있습니다.
  • 보관하는 것과 기간: 해시한 사용자 값, 날짜, 하루 사용 시간(초), 10분짜리 확인 기록입니다. 이틀이 지나면 매일 자동으로 지웁니다.
  • 한도와 비용: 무료 한도 안에서만 운영합니다. 한도가 끝나거나 응답이 1.5초보다 늦거나 인터넷이 끊기면 그 구간은 바로 PC가 처리하고 자막은 멈추지 않습니다. 이용자에게 요금을 받지 않습니다.
  • 상대방 음성: 같이 대화하는 사람의 목소리가 서버로 갈 수 있습니다. 켜기 전에 함께하는 사람에게 알려 주세요(6장).
  • 끄기와 거부: 설정에서 스위치를 끄면 다음 구간부터 보내지 않습니다. 켜지 않아도 앱 이용에는 아무 불이익이 없습니다.

이 버전은 개인 API를 통한 외부 AI 번역 요청을 제공하지 않습니다. Steam 통신과 모델·팩·글꼴 다운로드는 별도 항목의 안내를 확인해 주세요.

모델·팩·글꼴 다운로드와 Steam 이용

정상적으로 동봉된 모델은 사용할 때마다 다시 내려받지 않습니다. 빠진 모델이나 선택 ASR 모델은 Hugging Face, 선택 번역 팩과 포함 글꼴 등은 고정된 GitHub Releases 배포물을 이용할 수 있습니다.

다운로드하면 배포처와 리디렉션·CDN에 HTTPS 요청이 발생하며 IP 주소·요청 경로·시각 등 통신 정보가 처리될 수 있습니다. 다운로드에 식별 정보가 전혀 포함되지 않는다고 설명하지 않습니다.

Steam 클라이언트, 설치·업데이트, 소유권 확인과 Steamworks 연동은 Valve·Steam의 별도 처리가 적용됩니다. Steam Cloud 설정이나 운영체제 백업·동기화, 이용자가 직접 공유한 자료도 앱의 로컬 처리와 구분합니다. 자동 전송 코드가 없다는 사실만으로 모든 파일이 어떤 상황에서도 기기 밖으로 나가지 않는다고 약속하지 않습니다.

6. 상대방 음성과 이용자의 선택

선택한 입력에는 다른 참여자의 음성이 포함될 수 있습니다. 이용약관 동의나 개인정보 안내 확인만으로 상대방의 동의 또는 모든 법적 처리 근거가 확보되는 것은 아닙니다. 본인이 참여하는 대화에서 사용하고, 필요한 안내·동의와 공유 권한을 확인해 주세요.

개인정보처리방침은 처리 내용을 알리는 문서입니다. 이 방침 전체를 확인했다는 이유로 음성 송수신, 모델 이용 조건이나 운영체제 권한까지 한꺼번에 동의한 것으로 보지 않습니다. 별도 동의가 필요한 항목은 해당 기능에서 구분해야 합니다.

이용자는 처리 정지·완전 종료, 필요한 로컬 파일의 선택 삭제를 할 수 있습니다. 현재 버전에서는 자막 파일 기록을 켤 수 없습니다.

통역 준비에서 테스트 기록을 끄면 현재 기록을 마무리하고 다음 시작부터 남기지 않습니다. 자체 기록 삭제는 이 기능이 검증한 JSON만 대상으로 합니다. 이전 자막 TXT, 일반 로그, 설정, 모델과 따로 내보낸 JSON 사본은 지우지 않습니다.

업데이트나 앱 제거가 이전 자막·로그·다운로드·백업, 외부 제공사에 이미 전송한 정보까지 모두 삭제하는 것은 아닙니다. 삭제할 위치와 범위를 확인하고 필요한 설정·모델을 보존해 주세요. 제공사나 Steam에 관한 요청은 각 서비스의 절차도 확인해야 합니다.

이전 버전에서 외부 서비스에 이미 전송한 정보와 이용자가 별도로 이용하는 서비스에 대해서는 다음 안내를 확인해 주세요.

보관·학습·삭제·처리 국가와 비용은 제공사·계정·선택 서비스에 따라 달라지며 온말이 일괄 보장하지 않습니다. 외부 전송이 필요한 기능에서는 실제 제공사와 처리 범위를 먼저 확인해 주세요.

7. 이메일 문의의 처리

온말에는 원음과 텍스트를 개발자에게 자동으로 올리는 별도 운영 서버, 광고·분석 수집이나 자동 크래시 전송 기능을 두지 않습니다. 이용자가 켠 클라우드 음성 인식의 중간 서버는 소리를 글자로 바꿔 돌려줄 뿐 저장하지 않습니다(5장). 개발자가 직접 받아 처리하는 개인정보는 이용자가 스스로 보낸 이메일 문의뿐입니다. 이 설명은 Steam 통신이나 다운로드처럼 다른 기능의 통신까지 없다는 뜻은 아닙니다.

처리 목적과 항목

문의 메일은 질문·오류 제보에 답하고, 아래 8장의 권리 행사 요청을 처리하는 데만 사용합니다. 처리하는 정보는 보낸 메일 주소, 메일에 적은 이름(적은 경우), 문의 내용과 이용자가 직접 첨부한 자료입니다. 처리 근거는 「개인정보 보호법」 제15조 제1항 제4호(이용 과정에서 이용자가 요청한 조치의 이행)입니다.

이메일 문의에 첨부한 로그·화면·자료는 문의를 처리하는 개발자에게 전달됩니다. 보내기 전에 대화·음성·다른 사람의 이름·계정 정보·개인 경로·비밀번호·API 키를 빼 주세요. 원본 음성이나 전체 대화, 신분증·주민등록번호는 보내지 마세요. 개발자는 민감정보나 고유식별정보를 요구하지 않습니다.
