사실 안내 갱신 2026-10-20 · Windows 0.3.2 후보 · 효력일 변경 아님

기본 음성 인식과 동봉 한영 번역은 내 PC에서 처리합니다.
개인 API 번역은 선택 사항이며, 모델·팩 다운로드와 Steam 자체 통신은 별도입니다.

출시 전 사실 안내입니다. Windows 0.3.2의 Playtest·본편 후보는 업로드됐으나 정식 출시는 보류 중입니다. 2026-10-20 17:22 KST 확인 기준 Playtest는 미활성이며, 상점 승인과 빌드 승인은 별개입니다. 법률 검토는 완료되지 않았습니다. 이번 갱신은 처리·저장·배포 사실을 정정하며, 개인정보 처리의 법적 근거·역할·국외 이전·보관 및 권리 행사 절차가 확정됐다는 뜻이 아닙니다. 설치된 앱과 기존 Steam 제출물의 문서가 이 페이지와 동일하게 교체됐다는 뜻도 아닙니다.

1. 온말이 처리하는 것

선택한 앱 또는 출력 장치의 음성

온말은 사용자가 선택한 앱(예: Discord) 또는 출력 장치의 소리를 캡처해 인식·번역합니다. 여기에는 다른 사람(팀원)의 음성이 포함될 수 있습니다. 같은 앱의 효과음과 대사가 함께 들어올 수 있으며, 팀원 음성만 자동 분리하는 기능으로 설명하지 않습니다.

처리 시작사용자가 시작 버튼 또는 시작/정지 단축키를 명시적으로 실행한 뒤 입력을 엽니다. 앱 실행·첫 안내 완료만으로 시작하지 않습니다.
원음 저장현재 기본 제품 흐름에 원음 파일 저장 기능은 없습니다. 메모리 버퍼와 추론 중간값으로 처리하며 모든 복사본의 즉시 완전 삭제를 보장하지 않습니다.
외부 전송현재 개인 API 번역 경로는 음성 파일을 보내지 않습니다. 선택 시 인식된 원문 등 텍스트가 전송됩니다 (§3).

직접 입력한 텍스트와 클립보드

Windows 후보는 직접 입력한 글을 번역하는 화면을 제공합니다. 마이크 한 문장 송신·Alt+M·읽어주기 기능은 제거됐습니다. 번역 결과를 명시적으로 복사하면 OS 클립보드에 들어갑니다. 다른 앱과 OS의 클립보드 기록·동기화 설정이 적용될 수 있습니다. 게임 채팅에 붙여넣는 것은 이용자 본인이며, 온말이 게임 창에 대신 입력하지 않습니다.

인식·번역 결과와 로그

자막 파일 기록과 상세 진단 로그는 기본 꺼짐입니다. 자막 기록을 켜면 확정된 줄의 시각·언어쌍·원문과, 있는 경우 번역문이 %LOCALAPPDATA%\Onmal\subtitles의 로컬 TXT에 저장됩니다. 기록을 꺼도 기존 파일은 삭제되지 않으며, 현재 코드에 자막 파일의 자동 보관 기한은 없습니다.

일반 Windows 앱·오류 로그는 별도로 %LOCALAPPDATA%\Onmal\logs에 생성됩니다. 상태·모델·런타임·실패 정보와 예외·장치·파일 경로 등이 포함될 수 있습니다. 발화 내용과 API 키는 일반·진단 로그에 기록하지 않도록 구현했습니다. 앱의 로컬 저장과 사용자의 백업·동기화·직접 공유는 구분해야 합니다.

설정값

선택한 앱·출력 장치·언어·자막 모양·기록 및 API 선호 등의 설정을 %LOCALAPPDATA%\Onmal\settings.json에 저장하고 재실행 시 다시 사용합니다.

API 키 (선택)

Windows는 현재 사용자 계정 범위의 DPAPI로 키를 보호한 값을 설정 파일에 저장합니다. 모든 백업·계정 침해 상황에서의 안전성을 보장하는 것은 아닙니다. 사용 중에는 요청 인증을 위해 메모리와 제공사로 보내는 인증 헤더에 사용되며, 평문 키를 실행 인수나 로그에 넣지 않도록 구현했습니다.

2. 개발자에게 자동 전송되는 정보

현재 검토한 제품 코드에는 온말 자체 회원가입·분석/광고 도구·음성/텍스트 자동 업로드 서버·자동 크래시 전송 경로가 없습니다. 이 사실이 IP 주소·설정·텍스트가 어떤 상황에도 처리·저장되지 않는다는 뜻은 아닙니다.

문의에 이용자가 직접 첨부한 로그·화면·자료는 개발자에게 전달될 수 있습니다. 공유 전 내용을 확인해야 하며, 문의 자료의 보관·삭제·권리 행사 절차는 공개 운영 전 검토 항목입니다.

3. 외부 통신이 발생하는 경우

개인 API 번역과 연결 확인 (선택)

사용자는 OpenAI, Google Gemini, Anthropic, DeepL 중 하나의 개인 API를 선택할 수 있습니다. 수신 음성의 개인 API 번역은 기본 꺼짐이며, 키 저장만으로 번역 요청이 발생하는 것은 아닙니다. 텍스트 화면의 요청별 로컬/개인 API 선택과 별도의 연결 확인은 구분됩니다.

전송되는 것인식한 원문 또는 직접 입력한 텍스트, 언어·번역 지시·선택 API 모델 등 요청 정보와 인증 헤더
음성 파일현재 개인 API 번역 경로로 전송하지 않습니다.
경유지사용자 PC → 제공사. 온말의 별도 번역 중계 서버를 사용하지 않습니다.
연결 정보·요금제공사가 IP 주소 등 통신 정보를 처리할 수 있습니다. 번역·연결 확인은 외부 요청과 제공사 이용 요금이 발생할 수 있습니다.

전송된 정보의 보관·학습·삭제·지역 처리 조건은 각 제공사 방침을 별도로 확인해야 합니다 — OpenAI · Google · Anthropic · DeepL

모델·팩 다운로드와 Steam

기본 음성 인식·한영 번역 모델은 Steam 후보 배포물에 동봉하도록 구성했습니다. 정상 동봉 상태에서 기본 번역을 위해 첫 실행마다 모델을 내려받는 것은 아닙니다. 누락 모델·선택 음성 인식 모델은 Hugging Face, 선택 번역 팩·그 팩의 글꼴은 GitHub Releases 배포물을 사용합니다.

다운로드 시 배포처와 리디렉션/CDN에 HTTPS 요청이 발생하며 IP 주소·요청 경로·시각 등 통신 정보가 처리될 수 있습니다. Steam 설치·업데이트·소유권·Steamworks 통신은 Valve/Steam의 별도 처리입니다.

오류 기록과 문의

자동 크래시 리포트 전송 경로는 현재 제품 코드에 없습니다. 로컬 오류 로그는 위 §1과 같으며, 문의에 직접 첨부한 자료와 OS 백업·동기화는 자동 전송 여부와 구분합니다.

4. 다른 사람의 음성에 대하여

온말은 사용자 본인뿐 아니라 같은 음성 채널에 있는 다른 사람의 말을 처리합니다. 이 점을 분명히 밝히고, 다음을 설계에 반영했습니다.

  • 첫 실행 안내로 다른 참여자의 음성이 처리될 수 있음을 알립니다. 이 확인만으로 상대방 동의나 모든 법적 근거를 확보한 것은 아닙니다.
  • 현재 기본 제품 흐름에는 원음 파일 저장 기능이 없습니다. 선택 자막 기록·API 전송은 별도입니다.
  • 사용자가 참여 중인 음성 채널에서만 사용하도록 이용약관에 명시합니다.

이용자 책임 — 참여하지 않은 대화를 몰래 듣는 용도로 온말을 사용하는 것은 이용약관 위반이며, 거주 국가의 법(대한민국의 경우 통신비밀보호법)에 저촉될 수 있습니다.

5. 이용자의 권리

Windows의 로컬 처리와 관련해 다음 선택을 할 수 있습니다. 제공사·Steam·OS 백업의 데이터는 별도입니다.

열람%LOCALAPPDATA%\Onmal 폴더를 여십시오
로컬 파일설정·기록·모델의 위치와 필요한 백업을 확인한 뒤 원하는 파일을 관리합니다. 기록 끄기나 앱 제거만으로 이전 파일·백업이 모두 지워지는 것은 아닙니다.
API 키 삭제설정에서 제공사별 저장 키를 삭제할 수 있습니다. 제공사 계정의 키 폐기와 이미 전송된 데이터의 처리는 별도입니다.
처리 중지정지 버튼 또는 시작/정지 단축키(기본 Alt+Shift+P)를 사용하거나 앱을 완전히 종료합니다. 자막 숨김은 처리 정지와 다릅니다.

개인 API 사용 중단·자막 기록 끄기·키 관리가 이미 전송되거나 직접 공유한 자료의 삭제를 뜻하지는 않습니다. 문의 자료와 권리 행사 절차는 공개 운영 전 검토 대상입니다.

GDPR / 개인정보 보호법

로컬 처리만으로 개인정보 처리가 없거나 온말 개발자가 언제나 처리자가 아니라는 법적 결론을 내리지 않습니다. 처리 주체·목적·법적 근거·안내/동의·제공/국외 이전·보관 및 권리 행사 절차는 별도 검토가 필요합니다.

6. 아동

온말은 아동을 대상으로 하지 않으며, 아동 대상 기능이 없습니다. Steam의 연령 정책을 따릅니다.

7. 변경

이 방침이 바뀌면 앱 내 공지와 이 페이지에 게시합니다. 데이터 처리 방식에 실질적인 변경이 있는 경우, 변경 전에 앱 내에서 알립니다.
